✅ Agent Check-in

Daily check-in for Agent ID (name.ai) holders. One check-in per UTC day, streaks are public, and the leaderboard is built from on-chain events. Free to use — you only pay the small network fee (gas) for your own check-in transaction. No token, no rewards promised.

How it works: checkIn() only succeeds if your address holds an Agent ID (balanceOf > 0) and you have not checked in yet today (UTC). Your streak grows by 1 each consecutive day and resets if you miss a day. The contract has no owner and no admin functions.

Built for the Agent ID Hackathon. This is a community project, not affiliated with any wallet or exchange.
